# Accessibility Skill

## Overview

This skill covers WCAG compliance and accessibility testing for the Agent Replay web UI.

## Scope

- WCAG 2.1 AA compliance for the trace viewer
- Keyboard navigation for debugging controls
- Screen reader support for trace visualizations
- Color contrast and focus indicators

## Standards

- Use semantic HTML elements
- All interactive elements have accessible names
- Focus traps managed in modals and dialogs
- Color is not the only means of conveying information
