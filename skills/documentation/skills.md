# Documentation Skill

## Overview

This skill covers writing and maintaining technical documentation for the Agent Replay project.

## Scope

- README files for each package
- API documentation (TypeDoc)
- Usage examples and tutorials
- Architecture Decision Records (ADRs)
- Changelog and migration guides

## Standards

- Every public API must have JSDoc
- READMEs follow a standard template (description, install, usage, API, license)
- Examples are runnable and tested in CI
- ADRs are stored in `docs/adr/`
