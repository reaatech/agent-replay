# Code Review Skill

## Overview

This skill provides guidelines for conducting and participating in code reviews for the Agent Replay project.

## Scope

- Reviewing TypeScript code for correctness and style
- Checking test coverage and edge cases
- Validating API design consistency
- Security and performance review checklists

## Checklist

- [ ] Code follows TypeScript strict mode
- [ ] Tests are present and cover edge cases
- [ ] No `any` types without justification
- [ ] Error handling is comprehensive
- [ ] Public APIs have JSDoc comments
- [ ] No secrets or hardcoded credentials
- [ ] Performance implications considered
