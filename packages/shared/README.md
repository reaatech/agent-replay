# @reaatech/shared

Shared types, errors, and abstractions for Agent Replay.

## Exports

- **Trace Model** — `Trace`, `Span`, `Event`, `Checkpoint`, `TraceHeader`
- **LLM Abstractions** — `LLMRequest`, `LLMResponse`, `StreamChunk`, `RecordedStream`
- **Error Hierarchy** — `AgentReplayError`, `TraceNotFoundError`, `ReplayFailedError`, etc.
- **Storage Interface** — `TraceStorage`, `StorageOptions`
